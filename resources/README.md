# Resources

Resource pages linked from Aletheia Knowledge apps.

Shared visitor index:

`resources/index.html`

Naming convention for collection resource pages:

`aletheia-<app-name>-rsc.htm`

Rules:
- every resource page links back to `resources/index.html`;
- every resource page provides a route back to Swindon.org.uk;
- related PDFs and small companion guides should normally reuse the collection's existing resource page rather than creating another resource page;
- portable PDFs should include a visible backlink to the relevant Swindon.org.uk resource page where practical.
