Windows Debloat

The companion app is designed around reversible profiles rather than one giant “delete everything” switch.

  • ESU Controlled — keep security servicing available while controlling timing and driver changes.
  • Quiet Legacy — reduce unnecessary startup/background load while retaining essential protection.
  • Frozen / Isolated — for deliberately fixed legacy systems, with clear security warnings.

The full Debloat app is a separate Aletheia project and will link here when published.

Driver Recovery

Before changing drivers on an older PC, preserve what already works. Secret Windows documents PnPUtil driver export, hardware IDs, rollback and vendor-source checking.

Key idea: newest is not always best. A stable OEM driver may be safer than a newer generic replacement.

Registry & Recovery Pack

Windows 10 stopped automatically populating RegBack from version 1803. Secret Windows records how Microsoft documents re-enabling periodic registry backup.

The future Debloat app will also save the exact registry keys it changes into a timestamped Aletheia Recovery Pack before applying a profile.

Windows Update

Windows 10 ESU changes the purpose of Windows Update: it is primarily about security servicing rather than new Windows 10 features. Secret Windows keeps separate cards for ESU, driver exclusion, update control and recovery after a bad update.

Useful Windows Tools

Checked cards cover CMD, PowerShell, WinGet, networking, Event Logs, permissions, DISM/SFC, CHKDSK, Task Scheduler, Windows Server administration and modern replacements for retired commands such as WMIC.

Third-party tools

Useful external tools can complement Windows, but they remain optional. Examples worth evaluating include Rufus for Windows installation media, Microsoft Sysinternals for diagnostics, Malwarebytes for additional malware scanning, and Chris Titus Tech WinUtil for Windows maintenance/tweaking.

Any external tool should be checked against its current documentation and downloaded from its official source.
