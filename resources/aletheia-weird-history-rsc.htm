How free knowledge and resources fit together

Knowledge stays free and portable. Each verified card in aletheia-weird-history.md carries this resource-page URL. An AI, local app or search system can return the card and append the link. The resource page may earn income; the knowledge card itself contains no affiliate tracking code.

This separation lets Aletheia distribute useful knowledge widely without tying the knowledge format to Awin, Cloudflare or any other service. If an affiliate programme changes, only this page needs updating.
