# Aletheia Waste to Garden Knowledge Library

Version: 0.1
Date: 2026-09-21
App file: `aletheia-waste-to-garden.htm`

Purpose: an original, searchable gardening knowledge base for turning household and garden waste into useful growing, composting and reuse actions.

## Copyright / provenance note

This library **does not reproduce the text of the books**. It uses publicly visible book metadata, themes and project concepts as inspiration, then rewrites, corrects and expands the horticulture using current independent sources. Book links are provided so readers can find the original works.

Primary inspirations:
1. Compost: The Natural Way to Make Food for Your Garden — Ken Thompson (DK, 2007), project editor Annelise Evans. ISBN 9780756613419. Annelise Evans is credited as Project Editor.
   https://www.abebooks.co.uk/9780756613419/Compost-Natural-Way-Food-Garden-0756613418/plp
2. Grow It, Don't Throw It — Simon Akeroyd (DK, 2026). ISBN 9780241835784.
   https://dk.com/products/9780241835784-grow-it-dont-throw-it

Main modern evidence sources include RHS, Garden Organic and Cornell Composting.

## Evidence labels

- STRONG: well-established horticultural or composting principle supported by strong current guidance.
- GOOD: reliable practical guidance, though details vary by system/cultivar/context.
- PLAUSIBLE: biologically workable, but outcomes are variable or evidence is less formal.
- CAUTION: workable only with important safety, biosecurity or context limitations.
- NOVELTY: mainly decorative/experimental rather than an efficient growing method.
