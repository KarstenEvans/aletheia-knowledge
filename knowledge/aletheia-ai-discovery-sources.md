# Aletheia AI Knowledge — discovery source register

**Status:** research provenance / discovery map  
**Updated:** 2026-09-24  
**Canonical knowledge:** `aletheia-ai-knowledge.md`

## Purpose

This file records supplied publications that helped identify useful AI topics and design questions.

These publications are **discovery material**, not automatically authoritative evidence for every claim they contain. Aletheia AI Knowledge should independently check changing provider features and consequential factual claims against appropriate current sources before promotion into capability cards.

Do not copy protected prose, graphics or distinctive layouts into Aletheia Knowledge.

## Supplied sources reviewed in the September 2026 pass

### Directly useful for AI Knowledge

#### AI Fundamentals — The Cheat Sheet
Publisher/context: Property Filter, 2026.

Useful discovery themes:
- AI outcome depends on the combination of model, interface, tools and context;
- permissions should distinguish reading, drafting and sending/acting;
- repeatable workflows can be captured as Skills;
- treating an AI as a worker requires a real brief, tools and context rather than only Q&A.

Aletheia use:
- capability-stack card;
- action-permission ladder;
- Skill-versus-app rules.

#### AI Adoption For Dummies — WalkMe Special Edition
Publisher: Wiley / WalkMe, 2026.

Useful discovery themes:
- enterprise AI adoption depends on workflow context and cross-application execution;
- assistants/agents are incomplete without access to the real work context;
- guidance should appear where work happens;
- adoption should be governed as a workflow/change problem, not merely a model purchase.

Aletheia use:
- workflow integration before agent proliferation;
- context/tool/permission design;
- app interfaces that reduce copy/paste friction.

#### The State of Digital Adoption 2026 — WalkMe
Useful discovery themes:
- execution friction from app switching;
- lost workflow context;
- insufficient in-flow guidance;
- low trust and manual workarounds;
- shadow AI as a symptom of approved tools failing the work.

Aletheia use:
- keep project context inspectable;
- design adapters around real workflows;
- do not equate more tools/agents with more productivity.

#### The IT Guide — Becoming Frontier with Microsoft 365 Copilot and Agents
Publisher: Microsoft, 2026.

Useful discovery themes:
- staged progression from assistant use to specialised solutions and agentic workflows;
- governance, measurement and skills should accompany automation;
- agentic workflows are better introduced after the underlying process and data sources are understood.

Aletheia use:
- staged capability ladder;
- prove a workflow before automating it;
- separate assistant, specialist workflow and agent execution.

#### Governing AI in 2026
Publisher: OneTrust, 2026.

Useful discovery themes:
- inventory where AI affects decisions;
- risk/rights assessment;
- transparency;
- role/accountability assignment;
- documentation/logging;
- post-deployment monitoring and incident handling.

Aletheia use:
- action receipts;
- explicit operator/authority roles;
- system inventory and review dates;
- evidence of governance rather than policy-only governance.

This is not a substitute for legal advice or checking the actual law in the relevant jurisdiction.

#### The AI Reset
Publisher: Superside, 2026.

Useful discovery themes:
- map the existing workflow before deciding where AI belongs;
- adoption barriers include skills, workflows, legal/IP concerns and quality;
- select high-impact, lower-risk starting points rather than deploying AI everywhere.

Aletheia use:
- app/Skill promotion test;
- workflow map in page/project specifications;
- pilot before automation.

#### The Ultimate Checklist for Adopting AI at Work
Useful discovery themes:
- define the business problem first;
- assess feasibility, data and infrastructure;
- set measurable goals;
- consider financial impact and workforce readiness.

Aletheia use:
- app/project intake;
- success criteria and stop criteria;
- evidence-led automation decisions.

## Research rule

When a discovery source suggests a useful principle:

```text
discovery source
    -> candidate claim / workflow lesson
    -> independent current check where factual/current
    -> Aletheia type + evidence status
    -> knowledge card or GUI/dev rule
```

Do not turn one vendor's marketing diagnosis into a universal fact merely because it is persuasive.
