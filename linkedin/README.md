# Aletheia LinkedIn Learning Library

[Aletheia Protocol](https://github.com/KarstenEvans/aletheia-protocol) · [Thalia Protocol](https://github.com/KarstenEvans/thalia-protocol/blob/main/THALIA_PROTOCOL.md)

Each collection gets a descriptive, standalone, crawlable HTML page, its own adjacent `*-page.md` specification, explicit `index.html` card and relevant source-traced knowledge notes in `../knowledge/`. This is a directory of independent editorial companions to original posts, not automated reposting, transcripts, endorsement or lead-collection.

First collection: Chris Donnelly's [12 Free AI Guides](aletheia-12-free-ai-guides.htm), sourced from two supplied screenshots and https://lnkd.in/p/e9PRGswQ. New [knowledge cards](../knowledge/aletheia-12-free-ai-guides.md) contain original Aletheia explanations, access limitations and exercises. Public [Knowledge folder](../knowledge/index.html) is explicitly indexed, as GitHub Pages does not auto-list directories.

Sources and optional clearly labelled affiliate book/gift links must stay separate. No auto-publishing of new collections without human approval. Source checks and full browser/live tests are recorded as distinct stages.
